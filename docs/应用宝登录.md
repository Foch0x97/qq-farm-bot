# 应用宝登录

在“添加账号”或“编辑账号”的登录标签栏中选择“应用宝登录”。该入口采用 [Go 项目](https://github.com/Aoluis1005/QQ-farm-BOT-GO) 的扫码与重连面板，使用微信扫码并在手机确认后，保存授权、获取游戏 Code 并启动账号。上游原有的输入 Code、微信扫码和 QQ 扫码入口继续使用原有流程。

“保存”保存重连开关、离线等待时间和次数。未完成授权时保存默认值；编辑已授权账号时保存该账号配置。“立即重连”用于已通过本入口保存授权且离线的账号。重新扫码会更新当前编辑的账号；添加时同一微信授权会复用已有账号。

默认开启自动重连，离线等待 3 分钟，重连上限 3 次，与 Go 版一致，每 30 秒扫描一次。因此首次重连可能比设定时间晚一个扫描周期。普通重连失败后下一轮扫描继续尝试；成功后保留累计次数，保存配置或手动重连会重置计数。游戏请求超时按 Go 策略恢复且不受次数上限约束；登录受限错误 1000016 会关闭自动重连。刷新授权失败时尝试已保存的 Code；授权失效需要再次扫码。

授权保存在 `core/data/yyb-scan-authorization.enc`，使用 AES-256-GCM 加密；密钥为同目录的 `yyb-scan-authorization.key`。备份与迁移请复制整个 `core/data`，两个文件必须一起保留。管理接口不返回 accessToken、refreshToken 或原始登录凭据。

本地自动测试覆盖扫码任务取消、并发确认、账号更新、授权保存和重连状态转换。实际微信授权是否长期有效，以及真实断线后的恢复，仍需使用自己的微信账号扫码后验证。腾讯服务使授权失效时，程序无法保证免扫码恢复。
