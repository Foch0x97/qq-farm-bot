## 维护约定

- 根目录只保留作为仓库入口的 `README.md`。
- 安装、部署、功能和用户配置写入根 README。
- 实现原理、协议研究和工具使用等专题内容写入 `docs/`。
- 功能、界面入口、配置项、默认值、运行方式或命令发生变化时，在同一次更新中同步根 README 和受影响的专题文档。历史测试与版本记录注明适用日期或版本。
- 文档链接使用相对于所在 Markdown 文件的路径，示例命令默认从仓库根目录执行。
- 新增专题文档后同步更新本索引和根 README 的“项目文档”章节。
